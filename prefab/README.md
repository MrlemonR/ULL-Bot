# prefab — ayar dosyaları

ULL-Bot'ta **Ayarlar → Görünüm → KAYDET** ayarlarını buraya `.json` dosyası
olarak yazar: görünüm, model ayarları (model, sıcaklık, bağlam uzunluğu…) ve
tüm kişilikler. **YÜKLE** bu klasördeki dosyaları listeler; seçtiğinin
ayarları uygulanır.

Başka bir bilgisayardan ya da birinden aldığın ayar dosyalarını da bu klasöre
atman yeterli. Ollama adresi makineye özel olduğu için dosyaya yazılmaz.
